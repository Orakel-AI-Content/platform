# 0009 – RSS 2.0 com resumo e guid estável

- Status: aceito
- Data: 2026-09-30

## Decisão

- `/rss.xml`, RSS 2.0, os 20 artigos mais recentes por `publishedAt` (só `kind: article`).
- Item: `title`, `link`, `guid isPermaLink="false"` = `<siteId>:<id>` (troca de slug não republica), `pubDate` (RFC 822), `description` (SEO ou do conteúdo), `dc:creator`, `category`.
- Só resumo: o corpo são blocos renderizados pelo blog; HTML completo fica para quando alguém pedir.
- `lastBuildDate` = publicação mais recente, nunca a hora do build (idempotência). `atom:link rel="self"`.

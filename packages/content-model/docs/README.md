# Documentação do content-model

Docs desta unidade. O que vale para o repositório inteiro está em `docs/` da raiz.

| Documento                          | Quando consultar                                                                                          |
| ---------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `project-spec.yaml`                | Decisões desta unidade, com origem (herda as da raiz)                                                     |
| `architecture/overview.md`         | Papel no sistema, o que a v1 contém, regras do contrato                                                   |
| `architecture/code-design.md`      | Camadas, padrões de schema e de regra semântica, anti-padrões                                             |
| `architecture/folder-structure.md` | Onde criar cada arquivo; como acrescentar bloco, preset, regra ou versão                                  |
| `conventions/testing.md`           | O que testar, fixtures, como rodar                                                                        |
| `decisions/`                       | ADRs da unidade (0001 entrada; 0002 versões; 0003 snapshot e fixtures; 0004 idioma; 0005 imagem de teste) |

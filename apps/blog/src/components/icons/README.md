# Ícones

SVGs do [Lucide](https://lucide.dev) (`lucide-static` 1.49.0, licença ISC em `LICENSE`),
copiados como dados em `paths.ts`. Uso: `<Icon name="search" />`, sempre com texto ao lado.

| Nome                            | Onde                                  |
| ------------------------------- | ------------------------------------- |
| `menu`                          | Menu mobile do cabeçalho              |
| `search`                        | Caixa de busca                        |
| `rss`                           | Link do feed no rodapé                |
| `x`                             | Reservado: fechar (degrau 2)          |
| `chevron-left`, `chevron-right` | Botões do carrossel (`<ok-carousel>`) |
